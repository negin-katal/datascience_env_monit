Before you register

Three things happen outside your terminal, in this order, before you can generate a key at all. Start early — the first one has a waiting period.

A

Get your bwForCluster entitlement

Requested from your university. Takes 2–3 days to come through, so do this first.

Application form
B

Fill out the bwUniCluster questionnaire

A short survey required before your account can be created.

Questionnaire
C

Register for bwUniCluster in bwIDM

Creates your actual account on the cluster's identity system.

bwIDM login

Before you start

Have these three ready — everything below assumes them.

  • Your bwUniCluster registration is complete and your bwIDM account exists.
  • A terminal on your own laptop — macOS Terminal or the VS Code integrated terminal both work; they run the same shell.
  • Your two-factor / OTP method for bwIDM set up — you'll be asked for a code partway through.
1

Generate a key pair on your own machine

Open your terminal and run this locally — not while already SSH'd into another machine.

ssh-keygen -t ed25519 -f ~/.ssh/bwunicluster -C "your_email@example.com"

-t ed25519 sets the key algorithm — a fixed keyword, not anything personal. -f names the file so it won't collide with a key you already have. -C is just a label; your email works well.

When prompted, set a real passphrase — don't leave it empty. This key can reach your compute allocation, and later you can use it to connect from VS Code too.

Two files appear: bwunicluster (private — never share this) and bwunicluster.pub (public — this is the one you'll upload).

Windows: this exact command works unchanged in PowerShell. If ssh-keygen isn't recognized, enable it via Settings → Apps → Optional Features → Add a feature → OpenSSH Client, then reopen PowerShell.
2

Copy the public key

Print it and copy the full single line it outputs — it starts with ssh-ed25519.

cat ~/.ssh/bwunicluster.pub
3

Register the key in bwIDM

In the bwIDM portal, go to your account/profile area → Inbox → My SSH Pubkeys → Add SSH Key, then fill in:

  • SSH Key Name: bwunicluster (or any name you'll recognize later)
  • SSH Key: paste the full line from step 2 (starts with ssh-ed25519 AAAA…)

Click Add.

4

Confirm with your OTP

bwIDM asks for a one-time code before a new SSH key takes effect, since it grants account access. Enter the code from your authenticator app or hardware token to confirm.

5

Enable the key for bwUniCluster 3.0

Adding a key to your account doesn't automatically switch it on for a service. Go to Services → bwUniCluster 3.0 → Enable SSH Key, and under "Set SSH Key" select the key you just added, then link/enable it.

Propagation to the login nodes can take up to ~30 minutes. If your first login attempt fails, that's usually why — wait and try again before troubleshooting further.
6

Optional: add a shortcut in your SSH config

This lets you type ssh bwunicluster instead of the full hostname and key path every time. Edit the file with a text editor — don't type the path directly at the prompt, it isn't a command.

Windows: open Git Bash (installed with Git) and use the commands in the first tab below — recent Git for Windows installs include nano by default, so nothing changes for you. If Git Bash doesn't have nano, or you'd rather use PowerShell, use the second tab instead.

nano ~/.ssh/config

Paste this in, save (Ctrl+O, Enter), then exit (Ctrl+X):

Host bwunicluster
    HostName bwunicluster.scc.kit.edu
    User <your-bwidm-username>
    IdentityFile ~/.ssh/bwunicluster

If nano isn't available, paste this whole block instead — it writes the file directly:

cat >> ~/.ssh/config << 'EOF'
Host bwunicluster
    HostName bwunicluster.scc.kit.edu
    User <your-bwidm-username>
    IdentityFile ~/.ssh/bwunicluster
EOF
New-Item -ItemType Directory -Force -Path "$env:USERPROFILE\.ssh" | Out-Null

@"
Host bwunicluster
    HostName bwunicluster.scc.kit.edu
    User <your-bwidm-username>
    IdentityFile ~/.ssh/bwunicluster
"@ | Set-Content -Path "$env:USERPROFILE\.ssh\config" -Encoding ascii
If you've set up SSH before (e.g. for GitHub) and already have a .ssh\config file with entries in it, don't run this — Set-Content overwrites the whole file. Open it instead with notepad $env:USERPROFILE\.ssh\config and paste the four lines above below whatever's already there.

Your username here is the short localUid shown on your bwIDM profile (e.g. fr_ab1234) — not your email address. Double-check the exact login node hostname in your registration confirmation email or the bwHPC wiki, since it can vary by cluster generation.

7

Connect

ssh bwunicluster

You'll be asked for the passphrase you set in step 1 — that just unlocks your local private key, it's not sent anywhere.
